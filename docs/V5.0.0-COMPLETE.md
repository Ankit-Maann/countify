# Countify v5.0.0 — Complete Platform + AI Creator 4.0

This is the final 4.x/5.0 product baseline requested for the project. The AI Creator roadmap through 4.0 is implemented in one release so a future 5.0 release is not needed just to finish AI capabilities.

## AI Creator 4.0

- Natural English/Hindi/Hinglish and mixed-script input
- Typos, abbreviations and casual language
- Absolute and relative date intelligence
- Annual birthday/anniversary recurrence
- Ambiguity clarification
- Conversation history and local memory
- Optional authenticated Supabase conversation persistence
- Follow-up edits against a selected countdown
- Structured action protocol for create/update/delete/open/memory/reminder suggestion
- Destructive delete confirmation
- AI theme/accent/emoji/description/tag inference
- Voice input and optional browser speech output
- Local offline fallback
- Server-side OpenAI Responses API
- Daily AI quota protection
- Prompt-injection-aware instructions and bounded input
- No AI secret in the browser

## Existing platform retained

- Creator Studio, public countdowns, discovery, community, saved, profiles
- Design Studio and theme marketplace architecture
- Analytics, embeds and business/workspaces
- Pro/billing architecture and Stripe Edge Functions
- PWA/offline shell, install flow and service worker
- Security/RLS/validation/status pages
- Back/Home navigation on internal routes

## Production requirements

1. Apply `supabase/migrations/20261015_ai_creator_40.sql`.
2. Deploy `supabase/functions/ai-countdown`.
3. Set `OPENAI_API_KEY`, `OPENAI_MODEL=gpt-6-luna`, `AI_FREE_DAILY_LIMIT`.
4. Set frontend `VITE_AI_ENDPOINT` and Supabase public variables.
5. Keep Stripe/OpenAI/Supabase service secrets server-side.
6. Run `npm run verify`, `npm run lint`, and `npm run build` in an environment with dependencies installed before deployment.

The source package intentionally does not contain provider secrets or a built `node_modules` directory.
